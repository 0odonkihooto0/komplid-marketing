## Состояние репозитория

!`git status --short | head -20`

## Обязательные проверки

```bash
npx tsc --noEmit          # ноль ошибок типов
npm test                  # vitest, все тесты
npx next build            # сборка проходит, страницы статические
```

Без зелёного `tsc` не сообщать о готовности — это правило проекта (CLAUDE.md §1).

## Проверка изменённых страниц

Поднять `npx next start` и открыть затронутые адреса. Для новой статьи или
посадочной дополнительно:

- в `<head>` есть уникальные `title`, `description`, `alternates.canonical`;
- JSON-LD на месте: `ArticleSchema` + `BreadcrumbSchema` для статей,
  `SoftwareAppSchema` + `FaqSchema` для посадочных;
- FAQ-секция статьи попала в `FaqSchema` (извлекается из MDX автоматически);
- страница есть в `/sitemap.xml`, нет висячих URL на несуществующие роуты;
- на мобильной ширине читается, CTA доступен.

## Перед самим деплоем

Деплой запускает **пользователь** командой `./deploy.sh` — не Claude.
Напомнить: незакоммиченные изменения скрипт не пропустит; если обновлялся
раздел `/normativ`, push и сборка образа будут дольше обычного из-за объёма статики.
