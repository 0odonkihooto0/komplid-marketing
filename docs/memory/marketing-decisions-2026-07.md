Решения владельца проекта, принятые 2026-07-26 при планировании пре-лонча.

- **Непоставленные функции — переписать честно + блок «В разработке».** Не удалять молча
  и не оставлять как есть: заменить точным описанием того, что работает, а несделанное
  вынести в отдельный честный блок.
- **Выдуманные соцдоказательства — удалить сейчас**, компоненты `Metrics`/`Quote`/`SocialProof`
  оставить в коде под реальные цифры беты, когда они появятся.
- **GitHub Actions разрешены только для проверок на PR** (tsc + test + build, без секретов).
  Деплой остаётся ручным через `./deploy.sh`.
- **«Мой Ремонт» и «Исполнитель» — не в пре-лонч**, отдельной задачей.

**Why:** продукт в пре-лонче, клиентов нет, а ниша маленькая и инженеры дотошные — один
пост «а кто эти 312 команд?» в проф-чате дороже штрафа по ст. 5 ФЗ «О рекламе». Бренд
строится на инженерной честности (`BRAND_STRATEGY.md` §5.4), фальшивые цифры ей противоречат.

**How to apply:** любую новую цифру или заявление о функции проверять по коду приложения
([[app-feature-reality]], [[app-plans-and-prices]]), а не по планам и не по эталону лендинга.
Планы описывают желаемое, а не поставленное.

См. также [[prelaunch-status]].
