Сверка кода приложения (`C:\Komplid2copy`) 2026-07-26. Заявлять на сайте можно только левую
колонку — правая это ст. 5 ФЗ «О рекламе» (недостоверные сведения о преимуществах).

**Работает:** простая ЭП с GPS-привязкой и геозоной · PWA с офлайном (Serwist + IndexedDB) ·
голосовой ввод (Yandex SpeechKit) · фото с GPS · IFC/BIM-вьюер (собственный сервис на
IfcOpenShell) · импорт смет Гранд-Смета/РИК (XML, .gge, Excel) · AI-ассистент (Yandex AI
Studio, данные в РФ) · XML-экспорт по 12 XSD-схемам Минстроя для сдачи в ИСУП/Главгосэкспертизу ·
справочники ФСНБ-2022 (ГЭСН/ФСБЦ/ФСЭМ) внутри системы.

**НЕ поставлено:**
- **УКЭП / КриптоПро** — `SignatureDialog.tsx:23` это disabled-заглушка с комментарием
  «Фаза 4», в интеграциях `available: false` + бейдж «Скоро».
- **МЧД** — не найдена вообще: ни модели, ни роута, ни UI.
- **Интеграция с 1С** — только плитка в каталоге интеграций, API нет.
- **ФГИС ЦС вживую** — прод сознательно не ходит во внешний реестр, всё офлайн-справочники
  (`docs\fgiscs-sources.md`).
- **Прямая интеграция с ИСУП** — только формирование XML-пакета, машинной передачи нет.

**Профиль специалиста и лента заказов** («Исполнитель») с 2026-08-17 заявляются
как рабочая функция — решение владельца ([[prototypes-integration-2026-08]]).
В июле было записано обратное, поэтому цифру и состав перед следующей правкой
главной стоит сверить по коду приложения.
