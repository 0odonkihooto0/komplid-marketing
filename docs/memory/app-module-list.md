Модулей в приложении — **18**: 7 базовых (видны всегда) + 11 опциональных
(включаются на объекте через `enabledModules`). Число «18» на маркетинг-сайте верное.

Базовые: ИД · Все документы · Сметы · Договоры · Журналы · Фото · Команда
(плюс «Обзор» — дашборд, не модуль).

Опциональные: Паспорт · Документооборот (СЭД) · ПИР · ТИМ · ГПР · Ресурсы ·
Сертификаты · Стройконтроль · Отчёты · AI-ассистент · Связь.

Источник правды — `C:\Komplid2copy\stroydocs\src\lib\ui\object-modules.ts`,
пользовательские подписи в `src\lib\ui\nav-registry.ts`. При расхождении верить им.

**Осторожно с «13 модулей»**: это цифра из `C:\Komplid2copy\design\` — исторический
архив под старым брендом, его собственный README прямо говорит, что источником
правды он не является. Ту же цифру повторяет наш `design/landing-reference.html`.
