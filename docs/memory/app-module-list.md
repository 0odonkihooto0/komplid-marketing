Модулей на сайте заявлено **21**, в двух контурах: **14 в контуре объекта**
(всё, что происходит на стройке) и **7 в контуре организации** (портфель строек,
люди, обмен, справочники). Разбивка и названия — в `src/lib/home-data.ts`,
цифра для счётчиков — в `src/lib/proof-data.ts`.

Число подтверждено владельцем 2026-08-17 при внедрении прототипов: приложение
выросло с июля. **По коду приложения оно не сверялось** — при первой возможности
пересчитать по `C:\Komplid2copy\stroydocs\src\lib\ui\object-modules.ts`
и пользовательским подписям в `src\lib\ui\nav-registry.ts`. При расхождении
верить коду приложения, а не сайту.

История, чтобы не ходить по кругу: до августа 2026 сайт говорил «18 модулей»
(7 базовых + 11 опциональных по `object-modules.ts`), а `C:\Komplid2copy\design\` —
«13». Ни та ни другая цифра больше не актуальна; каталог `design\` источником
правды не является, его собственный README об этом прямо говорит.
